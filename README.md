
# 🐄 Dairy Farm Management System

A simple and efficient web-based application to manage daily operations of a dairy farm, including livestock records, milk production, sales, and inventory tracking.

## 🚀 Features

- 🐮 Livestock record management  
- 🥛 Milk production tracking  
- 💰 Sales & billing management  
- 📦 Inventory and feed management  
- 📊 Reports & analytics dashboard  
- 👤 Role-based access (Admin, Staff)

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS, JavaScript   
- **Backend:** Node.js  
- **Database:** MySQL 
- **Tools:** Git, GitHub, Postman  

## 🧑‍💻 How to Run

1. Clone the repo  
2. Set up the database using the provided SQL script  
3. Run backend server: `npm start` / `python manage.py runserver`  
4. Open frontend in browser
